## 1. Данные

- Binance Futures, свечи 5m, формат **RKB1**:
  - заголовок 32 байта: `'RKB1'`, затем `uint32 LE` — версия, число колонок (= 10), число строк n;
  - дальше n × 10 чисел `float64 LE`.
- Файлы помесячно: `<SYMBOL>/ГГГГ-ММ.bin`.
- Колонки: openTime (мс UTC), open, high, low, close, baseVol, quoteVol, trades, takerBuyBase, takerBuyQuote.
- Рабочий ТФ — **4H**. Свечи 4H, 1H и 1D собираются из 5m по UTC-окнам (4H: 00/04/08/12/16/20). Свеча 4H берётся, только если закрыта.
- **Время везде — время ЗАКРЫТИЯ свечи 4H, UTC.** «Сейчас» = закрытие последней свечи 4H.
- **Симуляция времени:** свеча за свечой. В каждый момент видно только прошлое. Будущее открывается только для проверки.
- **Период теста:** «сейчас» от 01.01.2026 00:00 до 31.08.2026 20:00 — 1458 шагов 4H.
- **Разгон:**
  - зоны v0.4 считаются с 15.11.2025 (архив с 17.08.2025, v0.4 нужно 90 дней истории);
  - цепочка каналов считается с 15.12.2025, отчёт с 01.01.2026.

## 2. База графика

- **База-линия ТФ** = для каждой свечи ТФ среднее центров тел 5m внутри неё (`(open+close)/2`), в логарифме. Свечи не рисуются как основа — только линия (конституция).
- **Кончики** (`yh`, `yl`) = самая высокая и самая низкая точка **часовой** база-линии (центры 5m → 1H) внутри свечи 4H, в логарифме; не ниже и не выше самой точки 4H.
  - **Линии каналов строятся по кончикам, а не по теням свечей.**
  - Тени свечей могут выходить за линии канала, это нормально.
- **Допуск ТФ (v0.4)** = K × медианный размах свечей этого ТФ: размах = ln(high/low), по закрытым свечам. K: 1H = 4,7, **4H = 3,05**, **1D = 2,0**.
  - Окно для медианы: 4H и 1D — вся история до «сейчас», 1H — последние 2880 свечей.
  - Пример: допуск 4H у SOL ≈ 6,1–6,2%, у HYPE ≈ 8,5–9,3%; допуск 1D у SOL ≈ 11,3%, у HYPE ≈ 14–15%.
- **Узлы v0.4** — упрощение Дугласа—Пекера по лог-базе-линии с допуском ТФ: точка остаётся, если отклоняется от хорды больше допуска (вертикально). Узел — вершина H или впадина L, если он выше или ниже обоих соседних узлов.
- **Значимая нога v0.4** — между соседними узлами H и L, не короче 1,33 × допуск ТФ.
- **Обычная нога 4H** (используется в засадах и пробоях) = медиана длины (в %) **6 последних значимых ног** этого направления на карте 4H в момент «сейчас». Если ног этого направления меньше 3 — берётся противоположное направление.

## 3. Зоны: только 1D, двумя линиями

**Как строятся** (тренажёр v0.4, `Trainer/core/geometry.js → mapTF`, код без правок):
1. Узлы базы-линии ТФ (§2).
2. Цены узлов сортируются и собираются в кластеры: соседние цены ближе 0,2 × допуск ТФ — один кластер. **Уровень** = среднее цен кластера.
3. **Зона** = уровень ± 0,2 × допуск ТФ: нижний край `lo`, верхний `hi`. Перед подсчётом визитов у свечей с размахом больше 8 × медианного тени ужимаются к телу (не дальше 1,5 тела).
4. **Визит** = свеча вошла в зону (тень коснулась), причём перед этим её в зоне не было. Зона засчитывается от **3 визитов**.
5. **Эпоха** — новая, если между визитами прошло больше 42 свечей ТФ.
6. **Статус:** «жив», если последний визит не старше 360 свечей ТФ; «стареет» — до 720; дальше «мёртв».

**Карта на каждый момент.** `zones_dump.js` на каждом закрытии 4H строит карты 1H, 4H и 1D только по прошлому, включая незакрытую свечу как живой край. Это поведение тренажёра по умолчанию.

**Решения Рагима:**
- Для графика 4H **основные зоны — только живые зоны 1D**. Мелкие (4H, 1H) — это масштаб часовиков, на 4H это шум.
- Зона используется и рисуется **как две горизонтальные линии** — `lo` и `hi`, без заливки.
- **Полуширина зоны 1D** `hw = 0,2 × допуск 1D` (лог), у SOL ≈ 2,3%, у HYPE ≈ 2,9%.

## 4. Канал: ядро (метод v2, код без правок — §15.5)

1. **Экран** — до 120 свечей 4H назад от «сейчас», включая «сейчас».
2. **Концы:** местная вершина по `yh` (выше левой, не ниже правой соседки) и местная впадина по `yl` (зеркально). Свеча «сейчас» концом не считается.
3. **Явность конца** = min(уход слева, уход справа): насколько цена отошла от конца в обе стороны, прежде чем его перекрыли.
   - Влево — до первой точки выше (для вершины), вправо — до первой точки выше или до «сейчас».
   - Уход считается по противоположным кончикам. Для впадины — зеркально.
4. **Лестница явности:** концы сортируются от самого явного к самому мелкому. На ступени m участвуют m самых явных концов (m = 3, 4, …).
5. **Канал по паре концов** (`try_pair`):
   - **главная линия** — через две точки одного вида: две впадины (`G='L'`, канал «по впадинам») или две вершины (`G='H'`, «по вершинам»);
   - **параллель** — через **самую дальнюю** противоположную точку ступени, правее первой точки линии; ширина `W` — расстояние до неё (лог);
   - **проверка «график не режет линии»:** ни один кончик после первой точки не уходит за главную линию или за параллель дальше допуска. Допуск в v2 = 15% W (`OUT`); в действующем варианте — §5, П2;
   - **начало канала** `s` тянется назад от первой точки, пока график внутри линий (с тем же допуском);
   - **точки на параллели** — противоположные кончики не дальше 20% W от неё (`TOUCH`). «Канал» — если таких 2+, «предполагаемый» — если 1.
6. **Пробой** — первое закрытие 4H после «сейчас» за любой линией дальше 15% W. **Ложный пробой — тоже пробой**, канал на нём заканчивается.
7. Канал считается **в логарифме цены**. На обычной шкале его линии слегка расходятся (вопрос открыт, §14).

## 5. Канал: какой выбрать — цепочка каналов (действующий вариант B)

### 5.1 Правила Рагима
1. **Канал = две точки на одной линии + параллель через точку на другой стороне.** «2+1» — уже канал.
2. **Канал держится до пробоя**, на каждой свече не пересчитывается.
3. **Каналы не пересекаются.** Точки нового канала — не раньше точки, с которой пошёл ход, пробивший старый. Начало нового канала может стоять на 1 свечу 4H раньше этой точки: экран поиска начинается со свечи перед ней (§15.8, `bound - 1`). Так посчитаны эталоны §12.3 (SOL 19.03, HYPE 26.03).
4. **Мелкие каналы внутри крупного возможны** — шаг Б, ещё не сделан (§14).
5. **Два противоположных вероятных канала** могут быть одновременно, пока один не подтвердится. После этого второй не рассматривается.
6. **Без порогов длины и ширины в числах.** Допуски — только доли ширины канала (v2) и доля допуска 4H (v0.4).

### 5.2 Алгоритм по свечам (шаг А, §15.8)
Состояние: **подтверждённый канал** (или нет), **два слота вероятных** (растущий и падающий), **граница начала хода**.

На каждом закрытии свечи `t`:
1. **Есть подтверждённый канал** — проверить пробой (§4 п.6).
   - Пробит → запомнить начало пробивающего хода (п.4 ниже), очистить канал и оба слота.
   - Не пробит → ничего не искать.
2. **Нет подтверждённого** — проверить пробой каждого вероятного.
   - Пробит ровно один из двух заполненных → он отпадает, **второй становится подтверждённым**, слоты очищаются.
   - Иначе пробитые просто очищаются; пробиты оба сразу — оба отпали.
3. **Поиск в пустые слоты** (только пока нет подтверждённого):
   - экран = от свечи перед границей начала хода до `t`, не длиннее 120 свечей; до первого пробоя — 120 свечей;
   - растущий слот ← **первый вариант на лестнице с наклоном > 0**, падающий ← **первый с наклоном < 0**;
   - найденный вариант держится до своего пробоя.
4. **Начало пробивающего хода:**
   - пробой вверх — самая низкая точка (`yl`) после **последнего касания верхней границы** (кончик не дальше 20% W от неё), до свечи пробоя включительно;
   - пробой вниз — самая высокая (`yh`) после последнего касания нижней;
   - касаний не было — от начала канала.

### 5.3 Две правки поиска пары (вариант B, §15.9)
- **П1. Не забывать крупные точки.**
  - В v2 пара всегда из **двух последних** точек вида на ступени, и новые мелкие точки вытесняли крупную прежнюю.
  - В варианте B: **вторая точка — самая свежая** точка вида на ступени; **первая — среди прежних точек того же вида на ступени по явности, от крупной к мелкой**. Первая пара, прошедшая проверку, — вариант.
  - Пара проверяется один раз. Исключение: если для неё ещё не было ни одной противоположной точки правее первой — проверяется на следующих ступенях.
  - Правилу «каналы не пересекаются» это не противоречит: экран начинается от начала хода.
- **П2. Допуск «режет линию»** = max(15% W, **0,2 × допуск 4H**). Пробой по-прежнему 15% W.
  - Пример: SOL 05.01.2026 12:00, канал по впадинам 03.01 08:00 (130,45) → 04.01 20:00 (133,45). В v2 он отброшен: впадина 03.01 16:00 ушла под линию на 0,34% при допуске 0,30% (канал шириной ~2%).

### 5.4 Важно: какой канал где стоит
- **Цепочка (вариант B)** — действующий способ выбора канала.
- **Скан засад (§6) и его эталоны (§12.1–12.2) посчитаны на канале v2 «первый на лестнице»:** экран 120, главный — первый вариант лестницы (`vs[0]`), выбирается заново на каждой свече. Каждый уникальный канал там берётся в последний момент, когда он был главным.
- **Цепочка в скан засад ещё не встроена.** Это не делалось и не согласовывалось. Не встраивать без «да» Рагима.

## 6. Засады (скан, действующая версия 19.11 — §15.7)

1. **Каналы для скана:** на каждом шаге главный = `vs[0]` лестницы v2. Уникальный канал = (вид линии, две её точки), берётся в последний момент, когда он был главным (`i`).
2. **Засада = стык:** граница канала, продлённая от «сейчас» (включительно) до 90 свечей вперёд, подходит к **линии зоны 1D** (`lo` или `hi` живой зоны 1D на момент `i`) **ближе 20% ширины канала** (`TOUCH`).
   - Верхняя граница даёт засады «ждём разворот вниз», нижняя — «ждём вверх».
   - **Берутся все линии, которые граница пересекает, без отбора по текущей цене** (правка 19.11: канал продолжается, наклонная граница позже пересекает линии, которые сейчас по другую сторону цены).
3. **Приход:** свеча коснулась линии тенью (сверху: high ≥ линии, снизу: low ≤ линии), **и в этот момент граница канала у этой линии** (не дальше 20% W).
   - Касание линии в середине канала приходом не считается.
   - Время прихода не обязано совпасть со временем стыка: смотрим по цене, пока граница у линии.
4. **До прихода канал пробит** (§4 п.6) → исход «канал пробит не у засады». Засада снимается: на пробое канал кончился.
5. **После прихода** (свеча прихода + 6 свечей):
   - **разворот** — закрытие ушло от линии назад на 0,5 допуска 4H (реакция v0.4: 0,5 допуска за 6 свечей);
   - цена ушла за линию дальше полуширины зоны 1D → дальше до 90 свечей:
     - **пробой с ходом** — закрытие ушло за линию на обычную ногу 4H;
     - **ложный пробой, возврат** — вернулось назад на 0,5 допуска 4H;
     - иначе **пробой без хода**;
   - ни того ни другого — **без реакции**.
6. **Нет прихода за 90 свечей** → «не дошла».
7. **Засада сработала** = разворот, пробой с ходом или ложный пробой с возвратом: у её цены сменилось направление (решение Рагима). Доля считается среди засад, к которым цена пришла.
8. **Счёт** (правка 19.11): на каждой стороне канала засады идут по времени стыка, каждая считается. Исключение: засада, у которой приход в пределах 6 свечей от уже засчитанного прихода на той же стороне этого канала — это тот же рывок. Засады без прихода считаются все.

### 6.1 Пробой у уровня засады («где канал будет пробит»)
- Пробой канала (§4 п.6) после `i`, до 90 свечей.
- «У уровня засады» = закрытие свечи пробоя не дальше полуширины зоны 1D от линии одной из засад этого канала, причём в сторону её границы (вверх — у засад верхней границы, вниз — у засад нижней).
- **Настоящий пробой** — после пробоя закрытие ушло в его сторону на обычную ногу 4H, не вернувшись внутрь канала. **Ложный** — вернулось внутрь раньше. Иначе — ни ноги, ни возврата.

## 7. Случайный контроль (обязателен для любого вывода)

- Засада сравнивается со **случайным уровнем на пути той же границы канала**: значение границы в случайный момент.
  - Сдвиг по времени берётся из сдвигов настоящих стыков той же стороны.
  - В версии 18.11 такой уровень дополнительно должен быть по ту же сторону от цены «сейчас», в 19.11 — без этого отбора.
- Для доли «сработала» — 50 копий на засаду. Для «пробит у уровня» — 200 прогонов, даётся среднее и разброс 2,5–97,5%.
- **Нельзя брать случайные уровни где угодно на графике.** Пробой всегда на границе, а засады лежат на границе по построению, поэтому такой контроль завышает успех. На HYPE он давал 25 вместо честных 38.
- Seed: засады — 17.

- **Края всех живых зон 1D** на этот момент — тонкие фиолетовые горизонтальные линии `#c08cff`, без заливки.
- **Каналы:**
  - подтверждённый — жёлтый `#ffe14d`, сплошной до «сейчас»;
  - вероятный растущий — оранжевый пунктир `#ff9f43`, вероятный падающий — голубой пунктир `#48dbfb`;
  - вперёд — точечное продолжение до пробоя, ✕ — пробой;
  - кружки — две точки главной линии на кончиках часовой линии `exp(yl[i])`/`exp(yh[i])` (они лежат на линии), колечко — точка параллели.

'use strict';
// ============================================================================
// core/data.js — Данные.
// 1) loadCoin(sym): читает весь архив 5m монеты в колонки (Float64Array).
// 2) TFSeries: серия одного ТФ, которая РАСТЁТ по одной закрытой 5m-свече.
//    Старшая свеча собирается только из закрытых 5m (конституция §4):
//    пока ТФ-свеча не достроена, она «незавершённая» (partial), но каждый её
//    кирпич — закрытая 5m. Одинаково для истории и для живого режима.
// Будущего серия не знает: в неё попадает только то, что подал clock.
// ============================================================================

const fs = require('fs');
const path = require('path');
const cfg = require('../config');

const COLS = ['t', 'o', 'h', 'l', 'c', 'v', 'qv', 'trades', 'tbb', 'tbq'];

// ---------------------------------------------------------------------------
// Чтение архива монеты
// ---------------------------------------------------------------------------
function readRkbFile(file) {
  const buf = fs.readFileSync(file);
  const { MAGIC, HEADER_BYTES } = cfg.RKB;
  if (buf.length < HEADER_BYTES) throw new Error('файл короче заголовка');
  const magic = buf.toString('ascii', 0, 4);
  if (magic !== MAGIC) throw new Error(`чужой формат (magic="${magic}")`);
  const version = buf.readUInt32LE(4);
  const ncols = buf.readUInt32LE(8);
  const n = buf.readUInt32LE(12);
  if (ncols !== cfg.RKB.NCOLS) throw new Error(`ждали ${cfg.RKB.NCOLS} колонок, в файле ${ncols} (версия ${version})`);
  const expected = HEADER_BYTES + n * ncols * 8;
  if (buf.length !== expected) throw new Error(`битая длина: ${buf.length} байт, ждали ${expected}`);
  // Копия в выровненный буфер (смещение исходного Buffer может быть не кратно 8).
  const ab = buf.buffer.slice(buf.byteOffset + HEADER_BYTES, buf.byteOffset + expected);
  return { n, ncols, data: new Float64Array(ab) };
}

// Возвращает { sym, n, t, o, h, l, c, v, qv, trades, tbb, tbq, gaps[] }
function loadCoin(sym) {
  const dir = path.join(cfg.KLINES_DIR, sym);
  let files;
  try {
    files = fs.readdirSync(dir).filter(f => /^\d{4}-\d{2}\.bin$/.test(f)).sort();
  } catch (e) {
    throw new Error(`[Data] Failed to read folder ${sym}: ${e.message}`);
  }
  if (!files.length) throw new Error(`[Data] No month files for ${sym} in ${dir}`);

  const parts = [];
  let total = 0;
  for (const f of files) {
    try {
      const p = readRkbFile(path.join(dir, f));
      parts.push(p);
      total += p.n;
    } catch (e) {
      throw new Error(`[Data] Failed to read ${sym}/${f}: ${e.message}`);
    }
  }

  const out = { sym, n: total };
  for (const k of COLS) out[k] = new Float64Array(total);
  let row = 0;
  for (const p of parts) {
    const d = p.data, nc = p.ncols;
    for (let i = 0; i < p.n; i++, row++) {
      const b = i * nc;
      for (let k = 0; k < COLS.length; k++) out[COLS[k]][row] = d[b + k];
    }
  }

  // Проверка непрерывности (разрывы/дубли/обратный ход) — только отчёт, не правка.
  const gaps = [];
  const step = cfg.BASE_MS;
  for (let i = 1; i < total; i++) {
    const dt = out.t[i] - out.t[i - 1];
    if (dt !== step) gaps.push({ at: out.t[i - 1], next: out.t[i], missingBars: dt / step - 1 });
  }
  out.gaps = gaps;
  return out;
}

// ---------------------------------------------------------------------------
// TFSeries — растущая серия одного ТФ
// ---------------------------------------------------------------------------
class TFSeries {
  constructor(name, ms) {
    this.name = name;
    this.ms = ms;
    this.perBar = ms / cfg.BASE_MS;   // сколько 5m внутри одной свечи ТФ
    // Завершённые свечи ТФ (обычные массивы — растут по одной).
    this.t = []; this.o = []; this.h = []; this.l = []; this.c = [];
    this.v = []; this.qv = []; this.trades = []; this.tbb = []; this.tbq = [];
    // mid — база-линия: среднее ЦЕНТРОВ тел 5m внутри свечи ТФ (конституция §6.1.3)
    this.mid = [];
    this.cur = null;        // незавершённая (partial) свеча ТФ или null
  }

  // Подать одну ЗАКРЫТУЮ 5m. Возвращает true, если свеча ТФ этим баром закрылась.
  push(t, o, h, l, c, v, qv, tr, tbb, tbq) {
    const bucket = Math.floor(t / this.ms) * this.ms;   // UTC-выравнивание
    if (this.cur && this.cur.t !== bucket) {
      // Пришёл бар нового окна, а старое не добралось до полной длины —
      // значит внутри был разрыв архива. Закрываем как есть, помечаем.
      this._commit(true);
    }
    if (!this.cur) {
      this.cur = { t: bucket, o, h, l, c, v, qv, trades: tr, tbb, tbq, n5: 1, cs: (o + c) / 2 };
    } else {
      const k = this.cur;
      if (h > k.h) k.h = h;
      if (l < k.l) k.l = l;
      k.c = c; k.v += v; k.qv += qv; k.trades += tr; k.tbb += tbb; k.tbq += tbq; k.n5 += 1; k.cs += (o + c) / 2;
    }
    // Свеча ТФ закрыта, когда подан её последний 5m (по времени, не по счёту).
    if (t + cfg.BASE_MS >= bucket + this.ms) { this._commit(false); return true; }
    return false;
  }

  _commit(incomplete) {
    const k = this.cur;
    this.t.push(k.t); this.o.push(k.o); this.h.push(k.h); this.l.push(k.l); this.c.push(k.c);
    this.v.push(k.v); this.qv.push(k.qv); this.trades.push(k.trades); this.tbb.push(k.tbb); this.tbq.push(k.tbq);
    this.mid.push(k.cs / k.n5);
    if (incomplete || k.n5 !== this.perBar) {
      (this.incomplete || (this.incomplete = [])).push({ t: k.t, n5: k.n5, need: this.perBar });
    }
    this.cur = null;
  }

  get length() { return this.t.length; }

  // Незавершённая свеча (собрана из уже закрытых 5m) — для «живого» взгляда
  // на старших ТФ. null, если последняя свеча ТФ только что закрылась.
  partial() { return this.cur ? { ...this.cur, mid: this.cur.cs / this.cur.n5 } : null; }
}

module.exports = { loadCoin, TFSeries, COLS };

### 15.3 `Trainer/core/geometry.js` — узлы, зоны, ноги v0.4 (без правок)

```javascript
'use strict';
// ============================================================================
// core/geometry.js — ЭТАП 1: ГЕОМЕТРИЯ (карта графика).
// Перенос проверенного Python-движка (Engine/rk_baseline.py) + то, что решили:
//   • база-линия = среднее ЦЕНТРОВ тел 5m внутри свечи ТФ (§6.1.3);
//   • узлы = изгибы линии (упрощение Дугласа-Пекера по лог-цене), отдельный
//     зигзаг не строим;
//   • этажи = ЗОНЫ, куда садятся узлы в разное время; сила = отдельные визиты;
//     ЭПОХИ = разные периоды, когда цена жила у зоны (§6.1.5);
//   • роль зоны менялась (подходили и сверху, и снизу) — отмечается;
//   • волны (ноги) между вершинами и впадинами; коррекции не выбрасываются;
//   • ВСЕ ТФ сразу и СВЯЗЬ между ними: зона старшего ТФ = скопление узлов и
//     этажей младших; этаж младшего внутри зоны старшего = «спотыкание».
// Все допуски относительные к монете (см. config.GEOMETRY). Черновые.
// Будущего не видит: работает только с тем, что лежит в сериях ТФ.
// ============================================================================

const cfg = require('../config');
const G = cfg.GEOMETRY;
const GEO_TFS = Object.keys(G.TF);            // ['15m','1h','4h','1d'] — 5m только сырьё

// ---------------------------------------------------------------------------
// Вспомогательное
// ---------------------------------------------------------------------------
function median(arr) {
  if (!arr.length) return NaN;
  const a = Float64Array.from(arr).sort();
  const m = a.length >> 1;
  return a.length % 2 ? a[m] : (a[m - 1] + a[m]) / 2;
}

// Дуглас-Пекер по лог-цене, вертикальное отклонение, допуск абсолютный (доля).
// Точная копия simplify() из rk_baseline.py. Возвращает индексы узлов.
function simplifyIdx(y, tol) {
  const n = y.length;
  if (n === 0) return [];
  if (n === 1) return [0];
  const keep = new Uint8Array(n); keep[0] = 1; keep[n - 1] = 1;
  const st = [[0, n - 1]];
  while (st.length) {
    const [a, b] = st.pop();
    if (b <= a + 1) continue;
    let dmax = 0, im = a;
    const dx = (b - a) || 1e-9, ya = y[a], slope = (y[b] - ya) / dx;
    for (let i = a + 1; i < b; i++) {
      const d = Math.abs(y[i] - (ya + slope * (i - a)));
      if (d > dmax) { dmax = d; im = i; }
    }
    if (dmax > tol) { keep[im] = 1; st.push([a, im], [im, b]); }
  }
  const out = [];
  for (let i = 0; i < n; i++) if (keep[i]) out.push(i);
  return out;
}

// ---------------------------------------------------------------------------
// Карта одного ТФ
// ---------------------------------------------------------------------------
// se — TFSeries; withEdge — добавить незавершённую свечу как «живой край».
function mapTF(se, tfName, opts = {}) {
  const P = G.TF[tfName];
  const total = se.length;
  const win = opts.window != null ? opts.window : P.window;
  const from = win ? Math.max(0, total - win) : 0;

  // Окно: закрытые свечи + (по желанию) незавершённая как последняя точка линии.
  const t = se.t.slice(from), mid = se.mid.slice(from);
  let o = se.o.slice(from), h = se.h.slice(from), l = se.l.slice(from), c = se.c.slice(from);
  const part = opts.withEdge === false ? null : se.partial();
  if (part) { t.push(part.t); mid.push(part.mid); o.push(part.o); h.push(part.h); l.push(part.l); c.push(part.c); }
  const n = t.length;
  if (n < 10) return { tf: tfName, ready: false, reason: `мало свечей (${n})` };

  // Размах свечей монеты на этом ТФ (по закрытым) → относительный допуск.
  const ranges = [];
  for (let i = 0; i < n - (part ? 1 : 0); i++) if (l[i] > 0) ranges.push(Math.log(h[i] / l[i]));
  const medRange = median(ranges);
  const tol = opts.absTol != null ? opts.absTol : P.K * medRange;
  const floorTol = G.FLOOR_TOL_OF_TOL * tol;

  // Аномальные свечи-проколы: тени ужать к телу (только для визитов этажей).
  let cleaned = 0;
  if (G.ANOMALY_X) {
    h = h.slice(); l = l.slice();
    for (let i = 0; i < n; i++) {
      const r = Math.log(h[i] / l[i]);
      if (r > medRange * G.ANOMALY_X) {
        const bh = Math.max(o[i], c[i]), bl = Math.min(o[i], c[i]);
        const span = Math.abs(c[i] - o[i]) || bh * 0.001;
        h[i] = Math.min(h[i], bh + span * 1.5); l[i] = Math.max(l[i], bl - span * 1.5);
        cleaned++;
      }
    }
  }

  // --- Узлы (изгибы линии) ---
  const y = mid.map(Math.log);
  const idx = simplifyIdx(y, tol);
  const nodes = idx.map((i, k) => {
    let kind = '-';
    if (k > 0 && k < idx.length - 1) {
      const p = mid[i], pp = mid[idx[k - 1]], pn = mid[idx[k + 1]];
      if (p > pp && p > pn) kind = 'H'; else if (p < pp && p < pn) kind = 'L';
    }
    return { i, t: t[i], p: mid[i], kind };
  });
  // Последний узел — «живой край»: ещё может сдвинуться, не подтверждён.
  if (nodes.length) nodes[nodes.length - 1].edge = true;

  // --- Этажи-зоны: кластер цен узлов (как в движке), затем визиты/эпохи ---
  const prices = nodes.map(nd => nd.p).sort((a, b) => a - b);
  const clusters = [];
  for (const pr of prices) {
    const last = clusters[clusters.length - 1];
    if (last && (pr - last[last.length - 1]) / last[last.length - 1] <= floorTol) last.push(pr);
    else clusters.push([pr]);
  }
  const floors = [];
  for (const cl of clusters) {
    const lvl = cl.reduce((a, b) => a + b, 0) / cl.length;
    const lo = lvl * (1 - floorTol), hi = lvl * (1 + floorTol);
    const visits = [];
    let prevIn = false;
    for (let i = 0; i < n; i++) {
      const inb = l[i] <= hi && h[i] >= lo;
      if (inb && !prevIn) {
        // откуда пришла цена: сверху или снизу (для «роль менялась»)
        const from = i > 0 ? (c[i - 1] > hi ? 'above' : c[i - 1] < lo ? 'below' : 'in') : 'in';
        let react = false;
        if (i + G.REACT_BARS < n) {
          for (let j = i + 1; j <= i + G.REACT_BARS; j++) if (Math.abs(Math.log(c[j] / lvl)) >= G.REACT_OF_TOL * tol) { react = true; break; }
        }
        visits.push({ i, t: t[i], from, react });
      }
      prevIn = inb;
    }
    if (visits.length < G.MIN_VISITS) continue;
    // эпохи: разрыв между визитами больше EPOCH_GAP свечей → новая эпоха
    let epochs = 1;
    for (let k = 1; k < visits.length; k++) if (visits[k].i - visits[k - 1].i > G.EPOCH_GAP) epochs++;
    const lastAgeBars = (n - 1) - visits[visits.length - 1].i;
    const status = lastAgeBars < G.ALIVE_BARS ? 'жив' : lastAgeBars < G.AGING_BARS ? 'стареет' : 'мёртв';
    const fromAbove = visits.some(v => v.from === 'above'), fromBelow = visits.some(v => v.from === 'below');
    const lv = visits[visits.length - 1], pv = visits[visits.length - 2];
    floors.push({
      lvl, lo, hi, nodes: cl.length, visits: visits.length,
      reacts: visits.filter(v => v.react).length, epochs,
      firstT: visits[0].t, lastT: lv.t, lastAgeBars, status,
      roleChanged: fromAbove && fromBelow,
      lastFrom: lv.from, prevFrom: pv ? pv.from : null,
      lastGapBars: pv ? lv.i - pv.i : null,   // сколько свечей цена отсутствовала до последнего визита
    });
  }
  floors.sort((a, b) => b.lvl - a.lvl);

  // --- Волны (ноги) между чередующимися H/L; коррекции не выбрасываем ---
  const hl = nodes.filter(nd => nd.kind === 'H' || nd.kind === 'L');
  const legs = [];
  for (let k = 1; k < hl.length; k++) {
    const a = hl[k - 1], b = hl[k];
    if (a.kind === b.kind) continue;
    const pct = (b.p - a.p) / a.p * 100;
    legs.push({ t0: a.t, p0: a.p, t1: b.t, p1: b.p, dir: pct < 0 ? 'down' : 'up', pct,
                big: Math.abs(pct) >= G.WAVE_OF_TOL * tol * 100 });   // как в движке: длина ноги в %
  }

  const last = mid[n - 1];
  return {
    tf: tfName, ready: true, bars: n, from: t[0], to: t[n - 1], hasEdge: !!part,
    medRange, tol, floorTol, cleaned, price: last,
    nodes: nodes.map(({ t, p, kind, edge }) => ({ t, p, kind, edge: !!edge })),
    floors, legs,
  };
}

// ---------------------------------------------------------------------------
// Связь ТФ: зона старшего = скопление младших; этаж младшего внутри старшего
// ---------------------------------------------------------------------------
function linkTFs(maps) {
  const order = GEO_TFS.filter(tf => maps[tf] && maps[tf].ready);
  const overlap = (a, b) => a.lo <= b.hi && b.lo <= a.hi;
  for (let x = 0; x < order.length; x++) {
    const low = maps[order[x]];
    for (const f of low.floors) {
      f.insideOf = [];                       // зоны старших ТФ, внутри которых этот этаж
      for (let y = x + 1; y < order.length; y++) {
        for (const g of maps[order[y]].floors) if (overlap(f, g)) f.insideOf.push({ tf: order[y], lvl: g.lvl });
      }
    }
  }
  for (let y = 0; y < order.length; y++) {
    const high = maps[order[y]];
    for (const g of high.floors) {
      g.childFloors = {}; g.childNodes = {};  // скопление младших внутри зоны старшего
      for (let x = 0; x < y; x++) {
        const low = maps[order[x]];
        g.childFloors[order[x]] = low.floors.filter(f => overlap(f, g)).length;
        g.childNodes[order[x]] = low.nodes.filter(nd => nd.p >= g.lo && nd.p <= g.hi).length;
      }
    }
  }
  return maps;
}

// ---------------------------------------------------------------------------
// Карта монеты целиком (все ТФ) и разница между двумя картами (для журнала)
// ---------------------------------------------------------------------------
function mapCoin(seriesByTf, opts = {}) {
  const maps = {};
  for (const tf of GEO_TFS) {
    try { maps[tf] = mapTF(seriesByTf[tf], tf, opts); }
    catch (e) { maps[tf] = { tf, ready: false, reason: `[Geometry] Failed to map ${tf}: ${e.message}` }; }
  }
  return linkTFs(maps);
}

// Что изменилось в этажах одного ТФ между прошлой и новой картой.
// Только НАСТОЯЩИЕ события, а не перерасчётное мигание:
//  • визит — цена вошла в зону ПОСЛЕ прошлой карты;
//  • новая_эпоха — цена вернулась к зоне после долгого отсутствия (> EPOCH_GAP свечей);
//  • роль_сменилась — последний визит пришёл с другой стороны, чем предыдущий;
//  • этаж_родился / этаж_исчез / статус_этажа — сопоставление по БЛИЖАЙШЕМУ уровню.
function diffFloors(prev, next) {
  const ev = [];
  if (!prev || !prev.ready || !next || !next.ready) return ev;
  const nearest = (f, list) => {
    let best = null, bd = Infinity;
    for (const g of list) {
      if (!(f.lo <= g.hi && g.lo <= f.hi)) continue;
      const d = Math.abs(Math.log(f.lvl / g.lvl));
      if (d < bd) { bd = d; best = g; }
    }
    return best;
  };
  const since = prev.to;   // время последней свечи прошлой карты
  for (const f of next.floors) {
    const old = nearest(f, prev.floors);
    if (!old) { ev.push({ type: 'этаж_родился', tf: next.tf, lvl: f.lvl, visits: f.visits, epochs: f.epochs }); continue; }
    if (f.status !== old.status) ev.push({ type: 'статус_этажа', tf: next.tf, lvl: f.lvl, from: old.status, to: f.status });
    if (f.lastT > since) {
      ev.push({ type: 'визит', tf: next.tf, lvl: f.lvl, from: f.lastFrom, visits: f.visits });
      if (f.lastGapBars != null && f.lastGapBars > G.EPOCH_GAP) ev.push({ type: 'новая_эпоха', tf: next.tf, lvl: f.lvl, epochs: f.epochs, absentBars: f.lastGapBars });
      const sides = ['above', 'below'];
      if (sides.includes(f.lastFrom) && sides.includes(f.prevFrom) && f.lastFrom !== f.prevFrom) {
        ev.push({ type: 'роль_сменилась', tf: next.tf, lvl: f.lvl, from: f.prevFrom, now: f.lastFrom });
      }
    }
  }
  for (const f of prev.floors) if (!nearest(f, next.floors)) ev.push({ type: 'этаж_исчез', tf: next.tf, lvl: f.lvl });
  // новая завершённая нога
  const lp = prev.legs[prev.legs.length - 1], ln = next.legs[next.legs.length - 1];
  if (ln && (!lp || ln.t1 !== lp.t1)) ev.push({ type: 'нога', tf: next.tf, dir: ln.dir, pct: ln.pct, big: ln.big });
  return ev;
}

# RK · Каналы Этапа 1 · метод «Взгляд назад от сейчас» (v2, 18.11.2026)
# Один файл: архив 5m → линия 4H и кончики углов → концы и их явность → канал «на сейчас» → картинка.
# Запуск:
#   python rk_channels_v2.py <папка_монеты_5m> <ДД.ММ.ГГГГ ЧЧ:ММ>            картинка «на сейчас» (будущего нет)
#   python rk_channels_v2.py <папка_монеты_5m> <ДД.ММ.ГГГГ ЧЧ:ММ> --reveal   то же + что было дальше и где пробой
# Время — UTC, момент «сейчас» = закрытие последней свечи 4H не позже указанного времени.
# Нужен Python 3.11 или новее (используется datetime.UTC), numpy, matplotlib.
import os, sys, struct, math, datetime as dt, numpy as np

# ---------- константы метода (менять только с согласия Рагима) ----------
TF = 4 * 3600 * 1000          # рабочий ТФ 4H
TF_TIP = 3600 * 1000          # младший ТФ для кончиков углов: 1H
SCREEN = 120                  # экран: текущая свеча + 120 свечей 4H назад (20 дней)
OUT = 0.15                    # зазор: линия считается «порезанной/пробитой», если цена за ней дальше 15% ширины канала
TOUCH = 0.20                  # кончик «лёг на параллель», если он не дальше 20% ширины от неё

# ---------- 1. данные: архив RKB1 ----------
def load5m(folder):
    rows = []
    for f in sorted(x for x in os.listdir(folder) if x.endswith('.bin')):
        b = open(os.path.join(folder, f), 'rb').read()
        assert b[:4] == b'RKB1'; ver, ncols, n = struct.unpack_from('<III', b, 4)
        assert ncols == 10 and len(b) == 32 + n * ncols * 8
        rows.append(np.frombuffer(b, '<f8', n * ncols, 32).reshape(n, ncols))
    return np.concatenate(rows)                      # t, o, h, l, c, baseVol, quoteVol, trades, takerBuyBase, takerBuyQuote

def resample(d, ms):
    """Свечи ТФ по UTC-окнам. mid = среднее центров тел 5m ((open+close)/2) внутри свечи ТФ.
    Свеча берётся, если закрыта (пришла её последняя 5m) или за ней уже идёт следующее окно; незаконченная последняя — нет."""
    t, o, h, l, c = d[:, 0], d[:, 1], d[:, 2], d[:, 3], d[:, 4]; bucket = (t // ms) * ms; cen = (o + c) / 2
    out = {k: [] for k in ('t', 'o', 'h', 'l', 'c', 'mid')}; i = 0; n = len(t)
    while i < n:
        j = i
        while j < n and bucket[j] == bucket[i]: j += 1
        if t[j - 1] + 300000 >= bucket[i] + ms or j < n:
            out['t'].append(bucket[i]); out['o'].append(o[i]); out['h'].append(h[i:j].max()); out['l'].append(l[i:j].min())
            out['c'].append(c[j - 1]); out['mid'].append(cen[i:j].mean())
        i = j
    return {k: np.array(v) for k, v in out.items()}

def prep(folder):
    """y — база-линия 4H (лог); yh/yl — кончики: самая высокая/низкая точка часовой линии внутри свечи 4H (лог)."""
    d = load5m(folder); S = resample(d, TF); S1 = resample(d, TF_TIP)
    y = np.log(S['mid']); y1 = np.log(S1['mid'])
    a = np.searchsorted(S1['t'], S['t']); b = np.searchsorted(S1['t'], S['t'] + TF)
    yh = np.array([max(y1[p:q].max(), y[i]) if q > p else y[i] for i, (p, q) in enumerate(zip(a, b))])
    yl = np.array([min(y1[p:q].min(), y[i]) if q > p else y[i] for i, (p, q) in enumerate(zip(a, b))])
    T = [dt.datetime.fromtimestamp((x + TF) / 1000, dt.UTC).replace(tzinfo=None) for x in S['t']]   # время ЗАКРЫТИЯ свечи
    return S, y, yh, yl, T

# ---------- 2. концы и их явность ----------
def extremes(yh, yl, lo, t):
    """Все местные вершины (по yh) и впадины (по yl) экрана lo..t. Последняя свеча (t) концом не считается.
    Явность = min(подъём слева, спад справа) для вершины: насколько цена ушла от неё в обе стороны, прежде чем
    вершину перекрыли (влево — до первой точки выше её, вправо — до первой точки выше её или до «сейчас»). Для впадины — зеркально."""
    out = []
    for i in range(lo + 1, t):
        if yh[i] > yh[i - 1] and yh[i] >= yh[i + 1]:
            j = i - 1
            while j >= lo and yh[j] <= yh[i]: j -= 1
            left = yh[i] - yl[j + 1:i].min() if i > j + 1 else 0.0
            k = i + 1
            while k <= t and yh[k] <= yh[i]: k += 1
            right = yh[i] - yl[i + 1:k].min() if k > i + 1 else 0.0
            out.append((min(left, right), i, 'H'))
        if yl[i] < yl[i - 1] and yl[i] <= yl[i + 1]:
            j = i - 1
            while j >= lo and yl[j] >= yl[i]: j -= 1
            left = yh[j + 1:i].max() - yl[i] if i > j + 1 else 0.0
            k = i + 1
            while k <= t and yl[k] >= yl[i]: k += 1
            right = yh[i + 1:k].max() - yl[i] if k > i + 1 else 0.0
            out.append((min(left, right), i, 'L'))
    out.sort(key=lambda e: -e[0]); return out

# ---------- 3. линия по двум концам + параллель ----------
def try_pair(yh, yl, lo, t, G, a, b, tips):
    """G='L': главная линия по двум впадинам a<b, параллель — к противоположным кончикам (вершинам) tips.
    G='H': то же сверху. Возвращает канал или None."""
    X = np.arange(lo, t + 1)
    zl, zu = (yl[lo:t + 1], yh[lo:t + 1]) if G == 'L' else (-yh[lo:t + 1], -yl[lo:t + 1])   # переворот: работаем «как с впадинами»
    k = (zl[b - lo] - zl[a - lo]) / (b - a); line = zl[a - lo] + k * (X - a); rl = zl - line; ru = zu - line
    oc = [i for i in tips if i >= a]
    if not oc: return None
    W = max(ru[i - lo] for i in oc)                  # параллель — через САМЫЙ ДАЛЬНИЙ противоположный кончик
    if W <= 0: return None
    e = OUT * W
    if (rl[a - lo:] < -e).any() or (ru[a - lo:] > W + e).any(): return None   # график режет главную линию / вышел за параллель
    s = a                                            # начало канала: тянем назад, пока график не вышел за линии
    while s - 1 >= lo and rl[s - 1 - lo] >= -e and ru[s - 1 - lo] <= W + e: s -= 1
    tf = [i for i in tips if i >= s and ru[i - lo] >= (1 - TOUCH) * W]          # кончики, легшие на параллель
    r0 = zl[a - lo] - k * a
    ky, top, bot = (k, r0 + W, r0) if G == 'L' else (-k, -r0, -(r0 + W))
    return dict(G=G, a=a, b=b, s=s, k=ky, top=top, bot=bot, W=W, tf=tf, full=len(tf) >= 2, t=t)

# ---------- 4. лестница явности: канал «на сейчас» ----------
def scan(yh, yl, t):
    """Все варианты на шаге t в порядке лестницы: сначала по самым явным концам, потом добавляем следующие по явности."""
    lo = max(0, t - SCREEN); ex = extremes(yh, yl, lo, t); found = []; seen = set()
    for m in range(3, len(ex) + 1):
        C = ex[:m]
        for G in ('L', 'H'):
            mine = sorted(i for _, i, g in C if g == G); tips = sorted(i for _, i, g in C if g != G)
            if len(mine) < 2: continue
            a, b = mine[-2], mine[-1]                # два ПОСЛЕДНИХ явных конца одного вида
            if (G, a, b) in seen:
                v0 = next((v for v in found if (v['G'], v['a'], v['b']) == (G, a, b)), None)
                if v0 is not None and not v0['full']:        # та же пара: новые кончики могут сделать предполагаемый каналом
                    v = try_pair(yh, yl, lo, t, G, a, b, tips)
                    if v and v['full'] and abs(v['W'] - v0['W']) < 1e-12: v0.update(v, level=v0['level'])
                continue
            v = try_pair(yh, yl, lo, t, G, a, b, tips); seen.add((G, a, b))
            if v: v['level'] = m; v['tm'] = [a, b]; found.append(v)
    return found

def main_channel(vs):
    """Главный = первый на лестнице с 2+ кончиками на параллели. Нет — первый предполагаемый (1 кончик). Нет — None («канала нет»)."""
    return next((v for v in vs if v['full']), vs[0] if vs else None)

# ---------- 5. пробой (вперёд от «сейчас») ----------
def breakout(S, ch, t, horizon=90):
    """Пробой = первая свеча 4H после t, чья ЦЕНА ЗАКРЫТИЯ вышла за линию дальше 15% ширины. Ложный пробой — тоже пробой."""
    lc = np.log(S['c'])
    for j in range(t + 1, min(len(lc), t + horizon + 1)):
        q = (lc[j] - (ch['k'] * j + ch['bot'])) / (ch['top'] - ch['bot'])
        if q > 1 + OUT: return j, 'вверх'
        if q < -OUT: return j, 'вниз'
    return None, None

        L = [abs(l['pct']) / 100 for l in rec['maps']['4h']['legs'] if l['dir'] == d][-6:]
        return float(np.median(L)) if len(L) >= 3 else None
    def leg_of(rec, d):
        return rhythm(rec, d) or rhythm(rec, 'down' if d == 'up' else 'up')
    def qpos(ch, m):     # место закрытия в канале: 0 — низ, 1 — верх
        return (c4[m] - (ch['k'] * m + ch['bot'])) / (ch['top'] - ch['bot'])
    def border(ch, e, j): return ch['k'] * j + ch[e]

    # 1. Главный канал на каждом шаге = ПЕРВЫЙ вариант на лестнице явности v2 (2 точки + параллель через точку)
    last, nsteps, changes, prev = {}, 0, 0, None
    for i in steps:
        vs = V.scan(yh, yl, i); ch = vs[0] if vs else None; nsteps += 1
        key = (ch['G'], int(ch['a']), int(ch['b'])) if ch else None
        changes += key != prev; prev = key
        if ch: last[key] = (i, ch)          # канал берётся в последний момент, когда он был главным

    # 2. Пробой каждого уникального канала (v2) и его исход
    brk = {}
    for key, (i, ch) in last.items():
        rec = Z[closeMs[i]]; jb, bd = V.breakout(S, ch, i)
        r = dict(i=i, jb=jb)
        if jb:
            d = 'up' if bd == 'вверх' else 'down'; leg = leg_of(rec, d); real = False; back = None
            for m in range(jb + 1, min(N, jb + HZ + 1)):
                if 0 <= qpos(ch, m) <= 1: back = m; break                       # вернулась в канал — ложный
                if (c4[m] - c4[jb]) * (1 if d == 'up' else -1) >= math.log(1 + leg): real = True; break
            r.update(dir=d, real=real, back=back, along=(ch['k'] > 0) == (d == 'up'))
        brk[key] = r

    # 3. Засада: исход по цене, но только на границе канала
    def evaluate(ch, e, i, side, L, tol, leg, hw):
        W = ch['W']
        for j in range(i + 1, min(N, i + HZ + 1)):
            at_border = abs(border(ch, e, j) - L) <= TOUCH * W                  # граница у линии зоны
            touch = (side == 'up' and hi4[j] >= L) or (side == 'dn' and lo4[j] <= L)
            if not (touch and at_border):
                q = qpos(ch, j)
                if q > 1 + OUT or q < -OUT: return 'канал пробит не у засады', None
                continue
            s = 1 if side == 'up' else -1
            for m in range(j, min(N, j + REACT_BARS + 1)):
                if (L - c4[m]) * s >= REACT_OF_TOL * tol: return 'разворот', j
                if (c4[m] - L) * s >= hw:                                        # ушла за линию дальше полуширины зоны
                    for m2 in range(m, min(N, m + HZ + 1)):
                        if (c4[m2] - L) * s >= math.log(1 + leg): return 'пробой с ходом', j
                        if (L - c4[m2]) * s >= REACT_OF_TOL * tol: return 'ложный пробой, возврат', j
                    return 'пробой без хода', j
            return 'без реакции', j
        return 'не дошла', None

    amb = []
    for key, (i, ch) in last.items():
        rec = Z[closeMs[i]]; lp = c4[i]; tol = rec['maps']['4h']['tol']; hw = FLOOR_TOL * rec['maps']['1d']['tol']
        for e, side in (('top', 'up'), ('bot', 'dn')):
            leg = leg_of(rec, 'up' if side == 'up' else 'down')
            for z in (f for f in rec['maps']['1d']['floors'] if f['status'] == 'жив'):
                for edge in ('lo', 'hi'):

                    if jx is None: continue                                     # граница до линии не дойдёт — стыка нет
                    out, ja = evaluate(ch, e, i, side, L, tol, leg, hw)
                    amb.append(dict(key=key, i=i, t=T[i].isoformat(), side=side, e=e, L=L, price=float(math.exp(L)), jx=jx, off=jx - i,

    grp = collections.defaultdict(list)
    for a in amb: grp[(a['key'], a['side'])].append(a)
    first = [min(A, key=lambda a: abs(a['L'] - c4[a['i']])) for A in grp.values()]

    offs = collections.defaultdict(list)
    for a in amb: offs[a['side']].append(a['off'])
    def rand_level(a):
        L2 = border(a['ch'], a['e'], a['i'] + random.choice(offs[a['side']]))
        return a['L'] if (a['side'] == 'up' and L2 <= c4[a['i']]) or (a['side'] == 'dn' and L2 >= c4[a['i']]) else L2
    for a in first:
        a['rand'] = [evaluate(a['ch'], a['e'], a['i'], a['side'], rand_level(a), a['tol'], a['leg'], a['hw'])[0] for _ in range(NR)]

    GOOD = {'разворот', 'пробой с ходом', 'ложный пробой, возврат'}; NA = {'не дошла', 'канал пробит не у засады'}
    def score(rows):
        arr = [a['out'] for a in rows if a['out'] not in NA]; rr = [x for a in rows for x in a['rand'] if x not in NA]
        return dict(засад=len(rows), дошла=len(arr), сработала=sum(o in GOOD for o in arr),
                    доля=round(100 * sum(o in GOOD for o in arr) / max(1, len(arr)), 1),
                    случай=round(100 * sum(x in GOOD for x in rr) / max(1, len(rr)), 1),
                    исходы=dict(collections.Counter(a['out'] for a in rows)))

    byk = collections.defaultdict(list)
    for a in amb: byk[a['key']].append(a)
    def at(b, lv): return bool(b['jb']) and any(abs(c4[b['jb']] - L) <= hw and (('up' if s == 'up' else 'down') == b['dir']) for s, L, hw in lv)
    keys = list(byk); hits = []
    real_at = [k for k in keys if at(brk[k], [(a['side'], a['L'], a['hw']) for a in byk[k]])]

        пробой_у_уровня_засады=dict(каналов_со_стыками=len(keys), пробит_у_уровня=len(real_at),
                                    случай_среднее=round(float(np.mean(hits)), 1), случай_разброс=[int(np.percentile(hits, 2.5)), int(np.percentile(hits, 97.5))],
                                    из_них_настоящих=sum(brk[k]['real'] for k in real_at),
                                    из_них_вернулась=sum(1 for k in real_at if brk[k]['back'] and not brk[k]['real'])),

    return rep, amb, first, brk, T

# RK · Этап 1 · Цепочка каналов — шаг А (проба 19.11.2026, правила согласованы с Рагимом).
# Код v2 (rk_channels_v2.py) не меняется: база-линия, кончики, концы и явность, лестница, «две точки + параллель»,
# проверка «график не режет линии» и пробой берутся из него как есть.
# Правила шага А:
#  1. Канал держится до пробоя (пробой v2: закрытие 4H за линией дальше 15% ширины). На каждой свече заново не ищется.
#  2. Два слота — растущий и падающий. Пустой слот заполняется первым вариантом своего направления на лестнице явности v2
#     (наклон > 0 — растущий, < 0 — падающий). Найденный вариант держится до пробоя. Пока подтверждения нет, оба — «вероятные».
#  3. Подтверждение: если заполнены оба слота и один пробит — он отпадает, второй становится КАНАЛОМ (подтверждённым).
#     Пока канал подтверждён, новые варианты не ищутся (одно-уровневый шаг А; мелкие внутри — шаг Б).
#  4. Пробит подтверждённый канал — оба слота пусты; новые варианты ищутся только по точкам НЕ РАНЬШЕ начала пробивающего хода:
#     пробой вверх — самая низкая точка (кончик) после последнего касания верхней границы; вниз — самая высокая после последнего
#     касания нижней. Касание = кончик не дальше 20% ширины от границы (TOUCH v2). Нет касания — от начала канала.
#  5. Экран поиска не длиннее 120 свечей (SCREEN v2). Самый первый поиск — экран v2 от «сейчас».
import numpy as np
import rk_channels_v2 as V

OUT, TOUCH = V.OUT, V.TOUCH

def scan_from(yh, yl, t, lo):
    """Лестница v2 на экране lo..t (lo — индекс; сам lo+1 может быть концом)."""
    save = V.SCREEN
    try:
        V.SCREEN = max(3, min(save, t - lo))
        return V.scan(yh, yl, t)
    finally:
        V.SCREEN = save

def first_dir(vs, sign):
    return next((v for v in vs if np.sign(v['k']) == sign), None)

def qpos(c4, ch, j):
    return (c4[j] - (ch['k'] * j + ch['bot'])) / (ch['top'] - ch['bot'])

def move_start(yh, yl, ch, jb, up):
    """Начало пробивающего хода (правило 4)."""
    W = ch['W']; s = ch['s']
    if up:
        touch = [j for j in range(s, jb) if yh[j] >= ch['k'] * j + ch['top'] - TOUCH * W]
        a = (touch[-1] + 1) if touch else s
        return a + int(np.argmin(yl[a:jb + 1])) if jb >= a else s
    touch = [j for j in range(s, jb) if yl[j] <= ch['k'] * j + ch['bot'] + TOUCH * W]
    a = (touch[-1] + 1) if touch else s
    return a + int(np.argmax(yh[a:jb + 1])) if jb >= a else s

def run_chain(S, yh, yl, T, i0, i1):
    """Идёт по свечам i0..i1. Возвращает состояния по шагам и журнал событий."""
    c4 = np.log(S['c'])
    slots = {+1: None, -1: None}; conf = None; bound = None
    states, log = [], []
    def key(v): return (v['G'], int(v['a']), int(v['b']))
    for t in range(i0, i1 + 1):
        # пробои на закрытии свечи t
        if conf is not None:
            q = qpos(c4, conf, t)
            if q > 1 + OUT or q < -OUT:
                up = q > 1 + OUT
                log.append(dict(t=t, ev='пробит канал', ch=conf, dir='вверх' if up else 'вниз'))
                bound = move_start(yh, yl, conf, t, up)
                conf = None; slots = {+1: None, -1: None}
        else:
            broken = []
            for sg, v in slots.items():
                if v is None: continue
                q = qpos(c4, v, t)
                if q > 1 + OUT or q < -OUT: broken.append(sg)
            for sg in broken:
                log.append(dict(t=t, ev='отпал вероятный', ch=slots[sg], dir='растущий' if sg > 0 else 'падающий'))
            if len(broken) == 1 and slots[-broken[0]] is not None and slots[broken[0]] is not None:
                conf = slots[-broken[0]]; slots = {+1: None, -1: None}
                log.append(dict(t=t, ev='подтверждён канал', ch=conf))
            else:
                for sg in broken: slots[sg] = None
        # поиск вариантов для пустых слотов (только пока нет подтверждённого)
        if conf is None and (slots[+1] is None or slots[-1] is None):
            lo = (t - V.SCREEN) if bound is None else max(bound - 1, t - V.SCREEN)
            vs = scan_from(yh, yl, t, lo) if t - lo >= 4 else []
            for sg in (+1, -1):
                if slots[sg] is None:
                    v = first_dir(vs, sg)
                    if v is not None:
                        slots[sg] = v; log.append(dict(t=t, ev='найден вероятный', ch=v, dir='растущий' if sg > 0 else 'падающий'))
        states.append(dict(t=t, conf=conf, up=slots[+1], dn=slots[-1], bound=bound))
    return states, log
```

### 15.9 `rk_channel_chain2.py` — цепочка каналов, правки П1 и П2 — действующий вариант B

```python
# RK · Этап 1 · Цепочка каналов — шаг А + две правки 19.11.2026 (согласованы с Рагимом «дальше»).
# Шаг А (rk_channel_chain.py) и код v2 не меняются; здесь — копия поиска пары с двумя отличиями:
#  П1. Пара точек: вторая — самая свежая точка вида G на ступени лестницы; первая — подбирается среди прежних точек того же
#      вида на этой ступени ПО ЯВНОСТИ (от крупной к мелкой), первая пара, прошедшая проверку, — вариант.
#      (В v2 бралась пара из двух последних точек.) Точки только после начала хода — это обеспечивает экран шага А.
#  П2. Допуск «график режет линию» = max(15% ширины канала, 0,2 × допуск 4H v0.4). Пробой — как в v2 (15% ширины), без изменений.
import numpy as np
import rk_channels_v2 as V
import rk_channel_chain as CA

OUT, TOUCH = V.OUT, V.TOUCH

def try_pair2(yh, yl, lo, t, G, a, b, tips, emin):
    """Копия V.try_pair, отличие одно: e = max(OUT*W, emin)."""
    X = np.arange(lo, t + 1)
    zl, zu = (yl[lo:t + 1], yh[lo:t + 1]) if G == 'L' else (-yh[lo:t + 1], -yl[lo:t + 1])
    k = (zl[b - lo] - zl[a - lo]) / (b - a); line = zl[a - lo] + k * (X - a); rl = zl - line; ru = zu - line
    oc = [i for i in tips if i >= a]
    if not oc: return None
    W = max(ru[i - lo] for i in oc)
    if W <= 0: return None
    e = max(OUT * W, emin)
    if (rl[a - lo:] < -e).any() or (ru[a - lo:] > W + e).any(): return None
    s = a
    while s - 1 >= lo and rl[s - 1 - lo] >= -e and ru[s - 1 - lo] <= W + e: s -= 1
    tf = [i for i in tips if i >= s and ru[i - lo] >= (1 - TOUCH) * W]
    r0 = zl[a - lo] - k * a
    ky, top, bot = (k, r0 + W, r0) if G == 'L' else (-k, -r0, -(r0 + W))
    return dict(G=G, a=a, b=b, s=s, k=ky, top=top, bot=bot, W=W, tf=tf, full=len(tf) >= 2, t=t)

def scan2(yh, yl, t, lo, emin):
    """Лестница явности v2 на экране lo..t; пара по П1, допуск по П2."""
    ex = V.extremes(yh, yl, lo, t); found = []; seen = set()
    for m in range(3, len(ex) + 1):
        C = ex[:m]
        for G in ('L', 'H'):
            mine = [(e, i) for e, i, g in C if g == G]; tips = sorted(i for _, i, g in C if g != G)
            if len(mine) < 2: continue
            b = max(i for _, i in mine)                                   # самая свежая точка вида G
            for e_a, a in sorted(((e, i) for e, i in mine if i < b), key=lambda x: -x[0]):   # первая — по явности
                if (G, a, b) in seen: continue
                if not any(i >= a for i in tips): continue            # нет точки для параллели — попробуем на следующей ступени
                seen.add((G, a, b))
                v = try_pair2(yh, yl, lo, t, G, a, b, tips, emin)
                if v: v['level'] = m; found.append(v); break
    return found

def run_chain2(S, yh, yl, T, i0, i1, tol4h):
    """Как CA.run_chain, но поиск вариантов — scan2. tol4h(t) — допуск 4H v0.4 на момент t."""
    save_scan = CA.scan_from
    def scan_from2(yh_, yl_, t, lo):
        lo2 = max(lo, t - V.SCREEN, 0)
        return scan2(yh_, yl_, t, lo2, 0.2 * tol4h(t))
    CA.scan_from = scan_from2
    try:
        return CA.run_chain(S, yh, yl, T, i0, i1)
    finally:
        CA.scan_from = save_scan
```
