# Этап 2 — разбор данных по одному

## Что делаем со сканером в целом

1. **22.5 — только источник данных.** Все прогнозы и решения из него убираются: фазы, ЛОНГ/ШОРТ, SL/TP, баллы, вето, взведение, симулятор, вердикт снайпера. Внутри формул убираются оценки «бычий/медвежий» по жёстким порогам, остаются голые числа.
2. **Каждый показатель разбираем отдельно, в своём чате.** По каждому три вопроса:
   - **Информация** — что именно он измеряет, на каких ТФ, по закрытой или живой свече.
   - **Польза** — что он даёт сам по себе. Проверяем на архиве 5 монет (STRK, ENA, XRP, SOL, LTC, 13 мес.): что было после, отличие от обычного фона, первая половина против второй, проверка на случайность, сравнение хода с комиссией.
   - **Способ применения** — как его читать в одиночку: состояние, «как эта монета себя вела раньше в таком состоянии», вероятный прогноз.
3. **Объединяем только после разбора всех.** Сначала голоса внутри Этапа 2, потом Этап 3 сводит их с Этапом 1.
4. **Общие правила подсчёта:**
   - все ТФ собираются из 5m архива;
   - 5m и 15m считаются по закрытым свечам;
   - 1H, 4H и 1D — старшие, их живая свеча собирается из закрытых 5m;
   - тест идёт шагом 5m, чтобы не «видеть будущее».
5. **Тест сначала по архиву, онлайн потом.** То, чего нет в архиве (стакан, ликвидации, L/S), разбираем на онлайне.
6. **Один чат — один показатель.** В конце чата результаты записываются в документ, следующий чат начинается с него.
