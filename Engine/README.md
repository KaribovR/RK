# RK_ENGINE — офлайн-движок карты (Этап 1, для проверки глазом)

**Что это:** экспериментальный Python-движок, которым мы проверяли чтение графика
на архиве STRK. Он НЕ боевой сканер — он рисует картинки для глаза Рагима.
Боевой сканер (на Node, на сервере) НЕ рисует и считает иначе (см. конституцию).

**Назначение:** воспроизвести карту на БАЗЕ-ЛИНИИ (линия по центрам 5m → сужение
до ТФ), этажи (сила = визиты, живучесть), волны. Полная логика и все нюансы —
в `RK_VISION.md`, правила — в `RK_CONSTITUTION.md`.

## Файлы
- `rk_io.py` — чтение архива RKB1 (v1=7 колонок / v2=10, ncols из заголовка), ресемплинг, отсечение аномалий.
- `rk_baseline.py` — база-линия, упрощение (Дуглас-Пекер по лог-цене), этажи (визиты), волны.
- `rk_render.py` — отрисовка карты (лог-шкала, зоны цветом, узлы, волны).
- `run_demo.py` — связка всего + числовая сводка.
- `rk_steps.py` — ЭКСПЕРИМЕНТ: ступени внутри ног (передышки, отметка «на этаже») и кандидаты фигур (двойная/тройная вершина/дно, голова-плечи; засчитываются только пробоем). Допуски черновые.
- `run_steps.py` — запуск эксперимента со ступенями и фигурами, картинка + сводка.

## Запуск
```
pip install numpy pandas matplotlib
python3 run_demo.py <папка_с_bin монеты> <ТФ> <допуск_упрощения>
# пример:
python3 run_demo.py /путь/к/RK_DATA_v3/klines_5m/STRKUSDT 1h 0.06
python3 run_steps.py <папка_с_bin монеты> <ТФ> <допуск_грубо> <допуск_тонко> <картинка.png>
```
Папка монеты = где лежат помесячные `YYYY-MM.bin`. Картинка сохраняется в `/tmp/rk_map.png`.

## Параметры (ЧЕРНОВЫЕ — «по глазу», подлежат настройке с Рагимом)
- Упрощение линии: **1H tol ≈ 0.05–0.06** (~46 узлов/10нед), **4H грубее (~0.08+)**. Допуск АБСОЛЮТНЫЙ, не привязан к диапазону истории.
- Этажи: кластеризация rel_tol **0.012** (1.2%), сила = **отдельные визиты** (не сумма фракталов), реакция = уход ≥3% за 6 баров, живучесть жив/стареет/мёртв <45/<90/>90 дней, min_visits **3**.
- Аномалии: диапазон свечи > **8×** медианы → тени ужать к телу.
- Волны: значимая нога ≥ **8%**.

## СТАТУС (что работает / что нет)
Работает: чтение архива, база-линия, упрощение, этажи с живучестью, волны, отрисовка, слепой тест (карта до даты X ловит реакции после).
НЕ доделано (см. RK_VISION.md §15): короткие локальные полки; чистый ступенчатый ритм (счёт+соразмерность передышек); измерение волна→дно с запоминанием коррекции доведённое до сверки с глазом; подключение данных-свидетелей; настройка допусков по глазу; проверка на других монетах (BTC/ETH/XRP/ENA, особенно трендовых).

## Важно
- `run_demo.py` упрощает ВСЮ историю (демо). Для анализа этажи считать на свежем окне (~8–10 недель на 1H), исторические — на всей истории для закономерностей.
- Прежний подход (зигзаг по фракталам/по % отката) ОТВЕРГНУТ — срезал ступени. База-линия по центрам 5m его заменила.
